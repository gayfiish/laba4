## Выполненные задания

### Средней сложности

#### №6 — Генератор простых чисел

Реализован генератор `generate_primes()`, который выдаёт простые числа до указанного пользователем предела.

Для генерации значений используется оператор `yield`.

Также реализована функция `is_prime()` для проверки числа на простоту.

Файл: `prime_generator.py`

#### №8 — Декоратор замера времени выполнения функции

Реализован декоратор `measure_time()`, который измеряет время выполнения функции с помощью `perf_counter()`.

Для сохранения имени и метаданных исходной функции используется `functools.wraps`.

Файл: `timing_decorator.py`

#### №2 — Фильтрация чётных чисел

Реализована функция `filter_even_numbers()`, которая оставляет в списке только чётные числа.

Используются элементы функционального программирования:

- `filter()`;
- `lambda`.

Файл: `even_filter.py`

### Повышенной сложности

#### №4 — Фильтрация данных из файла через генератор

Реализована функция-генератор `filter_numbers_from_file()`.

Программа читает файл построчно и с помощью `yield` возвращает только числа, удовлетворяющие условию фильтрации.

Также предусмотрена обработка некорректных строк и отсутствия файла.

Файлы:

- `file_filter.py`;
- `numbers.txt`.

#### №10 — Собственный аналог reduce()

Реализована функция `custom_reduce()`, выполняющая последовательную свёртку элементов коллекции в одно значение.

Встроенная функция `functools.reduce()` не используется.

Работа функции продемонстрирована на:

- вычислении суммы чисел;
- вычислении произведения чисел.

Файл: `custom_reduce.py`

## Использованные элементы функционального программирования

В лабораторной работе использованы:

- lambda-функции;
- `filter()`;
- функции высшего порядка;
- генераторы и `yield`;
- декораторы;
- передача функций в качестве аргументов;
- последовательная свёртка данных.

В основных функциях также используются аннотации типов и docstring.
